# Changelog

All notable changes to this defensive lab project are documented here.

## [1.1.0] - 2026-05-14

### Added

- Unit tests for firewall parsing, IDS and Windows event summarization, inventory rendering, Markdown validation, and basic secret scanning.
- Executive summary report for recruiter and stakeholder review.
- Architecture Decision Records for segmentation, synthetic telemetry, and standard-library automation.
- Project roadmap with completed, planned, and future work.
- CI test step using Python `unittest`.

### Improved

- README navigation and project structure documentation.
- Setup guidance for local validation and evidence review.
- Documentation clarity around synthetic lab-only evidence.

## [1.0.0] - 2026-05-14

### Added

- Segmented virtual security lab documentation.
- Firewall, IDS, and Windows synthetic sample logs.
- Wazuh-style and Suricata-style configuration examples.
- Lab validation report and generated asset inventory.
- Detection coverage mapping and SOC incident walkthrough.
- Python scripts for parsing firewall logs and summarizing security events.
- GitHub Actions workflow for documentation, Python, and basic secret-scan validation.
